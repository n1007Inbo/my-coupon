# 📌 Pinterest Blog & Product Deals System

Welcome to the **Pinterest Blog & Product Deals System** documentation. This folder serves as the central record for future developers and AI agents working on this project. 

This system is designed to capture organic Pinterest traffic using highly visual product landing pages that feature direct affiliate links, comparison tables, visual hotspots, and copy-paste coupon card interactions. It is completely isolated from the homepage and store menus to protect your active PPC campaign flows.
